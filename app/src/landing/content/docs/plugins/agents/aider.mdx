[Aider](https://aider.chat) is a pair-programming CLI built around explicit file edits. It doesn't have a session-resume concept, but it does work well for small, focused issues.

<PlatformSupport macos="full" linux="full" windows="full" />

## Install

```bash
pip install aider-install && aider-install
```

Set your API key via Aider's normal config (`~/.aider.conf.yml` or env vars). Thanos doesn't manage credentials for you.

## Use

```yaml title="thanos.yaml"
agent: aider
```

## How it works

- **Launch:** `aider` runs in the worktree. Thanos pipes the issue prompt in via the normal Aider UX.
- **Activity tracking:** Aider doesn't emit a structured event log. Thanos writes `{workspace}/.thanos/activity.jsonl` based on terminal output classification — the pattern matcher knows Aider's common prompts (diff review, confirm apply, etc.).
- **PR + git tracking:** PATH wrappers for `gh` / `git` record PRs and commits.
- **Session resume:** Not supported.

## Environment variables

| Variable        | Set by Thanos | Purpose                    |
| --------------- | --------- | -------------------------- |
| `THANOS_SESSION_ID` | ✓         | Thanos session id              |
| `THANOS_ISSUE_ID`   | ✓         | Issue identifier           |
| `PATH`          | ✓         | Prepends `~/.thanos/bin`       |
| `GH_PATH`       | ✓         | Absolute path to real `gh` |

## Troubleshooting

<Accordions>
	<Accordion title="Aider hangs on file-edit confirmation">
		Aider prompts before applying diffs. If you want fully autonomous runs, configure Aider's `--yes-always` via
		`~/.aider.conf.yml`. Thanos won't inject this for you — it's your call whether the agent should auto-apply.
	</Accordion>
	<Accordion title="Dashboard cost shows $0">
		Thanos doesn't parse Aider's cost output. The cost column stays empty.
	</Accordion>
</Accordions>
