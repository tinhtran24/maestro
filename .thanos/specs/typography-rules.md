# Typography Rules

All page titles, dialog titles, section titles, button labels, and navigation items should use **Upper First Case (Title Case)**.
Examples:
✓ New Task
✓ Related Task
✓ Prompt Description
✓ Search Tasks
✓ Create Task
✓ Task Board
✓ Mission Control
✓ Whiteboard
✓ Select Folder
Avoid:
✗ new task
✗ NEW TASK
✗ new Task
✗ task board
