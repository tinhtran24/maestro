# Skill: Feature Spec

## When to use
Use before coding any feature.

## Workflow
1. Read the ticket.
2. Identify the user goal.
3. Define acceptance criteria.
4. Identify edge cases and risks.
5. Identify files likely to change.
6. Ask for approval when the plan changes scope.

## Exit criteria
- Acceptance criteria exist.
- Risks are listed.
- Files likely to change are recorded.
