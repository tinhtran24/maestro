# Skill: Tailwind UI

## When to use
Use when editing Tailwind-styled UI.

## Workflow
1. Follow existing tokens and spacing.
2. Preserve dense workbench layouts.
3. Verify responsive behavior for compact panes.
4. Avoid decorative styling that hides task information.

## Exit criteria
- Responsive states are covered.
- Visual consistency is recorded.
